# Datasets & provenance

Honest data provenance matters — interviewers can smell synthetic logs.

## `samples/` — bundled demo data (SYNTHETIC)
Generated by `scripts/generate_demo_data.py`. This exists ONLY so the platform
is runnable out of the box and for the smoke-test pipeline. **Do not quote
numbers from this data on a resume** — it's hand-shaped to demonstrate the flow.

- `samples/normal/baseline_normal.json` — 30 days of benign "jdoe" activity
  (weekday 9–6 logins, office apps, internal IPs) used to build baselines.
- `samples/attack/phishing_scenario.json` — the phishing → post-compromise chain
  (Word→encoded PowerShell→C2 beacon→rundll32) used to demonstrate detection.

## `external/` — REAL attack telemetry (you download this; git-ignored)
Use these for the metrics that go on your resume:

- **EVTX-ATTACK-SAMPLES** — real Sysmon/EVTX logs of actual ATT&CK techniques,
  labeled by technique. `git clone https://github.com/sbousseaden/EVTX-ATTACK-SAMPLES data/external/evtx`
- **Mordor / Security Datasets** — https://securitydatasets.com
- **Atomic Red Team** — run atomics on a Windows VM and capture your own Sysmon
  (the strongest flex: you generated the telemetry yourself).

Then:
```bash
python scripts/metrics.py --benign data/samples/normal --attack data/external/evtx --min-severity high
```
